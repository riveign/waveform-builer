Keys

  • [Hide or show the library. Your choice is remembered.
  • /Jump to search from anywhere. Opens the library first if it's hidden.
  • EscClose a peek (Peek mode only).

How it works

  • Rail, not gone. Collapsed, the library becomes a 48px rail: show-library, search, add a record.
  • Nothing resets. The library stays mounted. Search "mills", pick a chip, scroll, then collapse and expand. It's all still there.
  • A hidden filter shows a dot. While a search or chip is active, the rail's search icon carries a teal dot, so a filtered library never surprises you.
  • No column jumps. The library keeps its full width and the column clips it, so the table doesn't reflow mid-animation.
  • The line holds. The navbar's logo column shrinks with the sidebar (just 聴), so the logo|tabs edge stays on the sidebar edge.
